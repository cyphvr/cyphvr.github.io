One-time setup

Connect Discord OAuth

Use the existing Cypher application in the Developer Portal — not a new app.

  1. Open discord.com/developers/applications
  2. Select Cypher (client ID 1121314550969532476)
  3. Left sidebar → OAuth2
  4. Under Redirects, add exactly:
    https://cyphvr.xyz/dashboard/auth/callback
  5. Save changes
  6. Reset Secret, copy it once, paste into core/keys.py as DISCORD_CLIENT_SECRET
  7. Restart the bot, then come back here
